# MegaStats Forecast Lab

Independent reconstruction of the visible number-set and tracking app. Generates five random Mega Millions number sets, accepts user-entered sets, records dates and user-entered drawing results, compares saved sets, tracks a self-entered entertainment budget and prize log, and summarizes frequencies only within results entered by the user. Data stays in this browser and can be exported.

No usable source was found in the matching `AWEMISSIONS/MegaStats-Predictor` repository. The original live experience referred to official history and locked forecasts; its source and verified data feed were not available. This rebuild does not import stale draw data or claim predictive power. Lottery odds and official results should be checked with the lottery operator.
